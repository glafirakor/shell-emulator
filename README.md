# Эмулятор командной строки (вариант 9)

## Описание

Программа на Python, которая имитирует командную строку UNIX.
Сделаны этапы 1 (REPL) и 2 (конфигурация). Программа выводит приглашение, читает команды и отвечает на них. При запуске можно указать путь к VFS и путь к стартовому скрипту. Команды ls и cd пока заглушки, просто выводят свое имя и аргументы.

Структура:

- src/shell.py - код эмулятора
- tests/test_shell.py - автотесты
- tests/scripts/ - стартовые скрипты для эмулятора
- tests/os/ - скрипты ОС для проверки параметров запуска
- run.sh - скрипт запуска

## Функции

- get_prompt() - делает приглашение вида username@hostname:~$ из данных системы
- parse_input() - делит строку на команду и аргументы по пробелам, отбрасывает комментарий после #
- execute() - выполняет одну строку, возвращает False, если была ошибка
- cmd_ls() - заглушка ls, печатает аргументы
- cmd_cd() - заглушка cd, печатает аргумент, если аргументов больше одного - ошибка
- cmd_exit() - выход, можно указать код возврата числом
- cmd_conf_dump() - команда conf-dump, печатает параметры в виде ключ=значение
- config_lines() - собирает параметры в строки ключ=значение
- read_script() - читает файл стартового скрипта
- run_script() - выполняет стартовый скрипт, показывает ввод и вывод
- repl() - основной цикл программы
- parse_args() - разбирает параметры командной строки
- main() - запуск: параметры, отладочный вывод, скрипт, потом REPL

Команды: ls, cd, exit, conf-dump

## Настройки

Параметры командной строки:

- --vfs ПУТЬ - путь к физическому расположению VFS
- --script ПУТЬ - путь к стартовому скрипту

При запуске все параметры выводятся строками [debug].

Стартовый скрипт - текстовый файл, одна команда на строку. Комментарии пишутся через # (как в Python), пустые строки пропускаются. При выполнении на экран выводится приглашение с командой и результат, как будто команду ввели руками. Если в строке ошибка, выводится сообщение с номером строки и выполнение продолжается. После скрипта запускается обычный режим ввода.

Ошибки: неизвестная команда, неверные аргументы, незакрытая кавычка, стартовый скрипт не найден, неизвестный параметр запуска.

## Запуск

Нужен Python 3. Собирать ничего не надо.

Запуск эмулятора:

```
./run.sh
./run.sh --vfs vfs/minimal.xml --script tests/scripts/startup.txt
```

Запуск автотестов:

```
./run.sh test
```

Скрипты ОС для проверки параметров:

```
sh tests/os/test_vfs.sh
sh tests/os/test_script.sh
sh tests/os/test_all.sh
```

## Примеры

Запуск со стартовым скриптом:

```
$ ./run.sh --script tests/scripts/startup.txt
[debug] vfs=не задан
[debug] script=tests/scripts/startup.txt
glafira@MacBook-Pro-Glafira:~$ conf-dump
vfs=не задан
script=tests/scripts/startup.txt
glafira@MacBook-Pro-Glafira:~$ ls
ls: аргументы = []
glafira@MacBook-Pro-Glafira:~$ ls -l docs  # комментарий в конце строки
ls: аргументы = ['-l', 'docs']
glafira@MacBook-Pro-Glafira:~$ cd docs
cd: аргументы = ['docs']
glafira@MacBook-Pro-Glafira:~$
```

Ошибки в стартовом скрипте:

```
glafira@MacBook-Pro-Glafira:~$ unknown_command
unknown_command: команда не найдена
ошибка в стартовом скрипте tests/scripts/errors.txt, строка 4
glafira@MacBook-Pro-Glafira:~$ cd a b
cd: слишком много аргументов
ошибка в стартовом скрипте tests/scripts/errors.txt, строка 5
```
