# Эмулятор командной строки (вариант 9)

## Описание

Программа на Python, которая имитирует командную строку UNIX.
Сейчас сделан этап 1 (REPL): программа выводит приглашение, читает команды и отвечает на них. Команды ls и cd пока заглушки, просто выводят свое имя и аргументы.

Структура:

- src/shell.py - код эмулятора
- tests/test_shell.py - тесты
- run.sh - скрипт запуска

## Функции

- get_prompt() - делает приглашение вида username@hostname:~$ из данных системы
- parse_input() - делит строку на команду и аргументы по пробелам
- execute() - выполняет одну введенную строку
- cmd_ls() - заглушка ls, печатает аргументы
- cmd_cd() - заглушка cd, печатает аргумент, если аргументов больше одного - ошибка
- cmd_exit() - выход, можно указать код возврата числом
- repl() - основной цикл программы

Команды: ls, cd, exit

Ошибки: неизвестная команда, неверные аргументы у cd и exit, незакрытая кавычка.

Настроек пока нет.

## Запуск

Нужен Python 3. Собирать ничего не надо.

Запуск эмулятора:

```
./run.sh
```

Запуск тестов:

```
./run.sh test
```

## Примеры

```
glafira@MacBook-Pro-Glafira:~$ ls
ls: аргументы = []
glafira@MacBook-Pro-Glafira:~$ cd папка
cd: аргументы = ['папка']
glafira@MacBook-Pro-Glafira:~$ cd a b
cd: слишком много аргументов
glafira@MacBook-Pro-Glafira:~$ привет

```
